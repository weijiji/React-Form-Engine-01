# Sitemap：动态表单引擎

> 版本：v1.0
> 日期：2026-08-05
> 来源：基于产品规格 v1.0、UX 设计规格 v1.0、设计规格 v1.0 综合推导
> 原则：权限码驱动导航 —— 侧边栏为一份统一导航，按用户权限码过滤（ADR-0010），无门户概念

---

## 1. 导航模型总览

系统采用**权限码驱动导航模型**（ADR-0010），五个角色按权限码看到不同的导航分区（不再是独立门户）；`/designer` 等前缀仅作纯路径组织：

| 角色 | 路由前缀 | 设备 | 环境 |
|------|---------|------|------|
| 模板设计者 | `/designer` | 桌面端 | UAT |
| 表单填写者 | `/filler` | PC + 移动端 | UAT/PROD |
| 审批人 | `/approver` | 移动端优先 + PC | UAT/PROD |
| 系统管理员 | `/admin` | 桌面端 | UAT/PROD |
| 运维人员 | `/ops` | 桌面端 | PROD |

---

## 2. 公共页面

所有角色均可访问：

```
/login                              # 登录页
/403                                # 权限不足（"你没有权限访问此页面"）
/404                                # 页面不存在
/notifications                      # 通知中心（站内通知列表）
```

## 3. 模板设计区域 `/designer`

> 设备：桌面端（大屏 + 键鼠） | 环境：UAT
> 能力：设计表单、删除表单模板、导出/导入配置

```
/designer
│
├── /designer/templates             # 我的模板 — 模板列表页
│   │                                #   - 已发布 / 草稿分类筛选
│   │                                #   - 每项显示：名称、描述、状态、最后修改时间
│   │
│   └── /designer/templates/:id     #   模板详情（只读视图）
│                                    #   - 他人签出时强制只读
│                                    #   - 提示："该模板正由 [用户名] 编辑中"
│
├── /designer/create                # 创建表单 — 入口选择
│   │
│   ├── /designer/create/nl         #   NL 对话创建界面
│   │                                #   - 自然语言描述表单需求
│   │                                #   - AI 生成表单结构预览
│   │                                #   - 快捷示例入口（请假、采购、报销等）
│   │                                #   - 生成后 → 跳转至设计器
│   │
│   └── /designer/create/blank      #   空白模板创建
│                                    #   - 输入名称、描述、分类
│                                    #   - 创建后 → 自动签出 → 进入设计器
│
├── /designer/edit/:templateId      # 设计器 ⭐ 核心界面
│   │                                #   三栏布局：
│   │                                #   ├ 左：组件面板 (240px)
│   │                                #   │   - 布局组件：Section 章节容器
│   │                                #   │   - 基础控件：文本输入、多行文本、数字输入、下拉框
│   │                                #   │   - 选择控件：单选按钮、多选框
│   │                                #   │   - 日期控件：日期选择、日期时间
│   │                                #   │   - 高级控件：文件上传、人员选择
│   │                                #   │   - 交互：点击添加 / 拖拽到预览区或结构树
│   │                                #   │
│   │                                #   ├ 中：实时预览 (flex:1)
│   │                                #   │   - 所见即所得的表单渲染
│   │                                #   │   - 双模式：静态预览 | 交互测试（独立 Store）
│   │                                #   │   - 操作按钮：[保存草稿] [发布]
│   │                                #   │
│   │                                #   └ 右：结构树 + 属性面板 (360px)
│   │                                #       - 结构树：层级展示章节→字段，支持拖拽排序
│   │                                #       - 属性面板：选中字段后显示
│   │                                #         - 基本：标签、占位提示、默认值、必填
│   │                                #         - 验证：长度/范围/正则/文件限制
│   │                                #         - 高级：条件联动（可视化条件编辑器）
│   │
│   ├── (审批链配置)                 #   设计器内子面板/Tab
│   │                                #   - 添加/删除/排序审批节点
│   │                                #   - 每节点配置审批人规则：
│   │                                #     - 组织架构（直属上级）
│   │                                #     - 指定角色
│   │                                #     - 指定人员
│   │
│   └── (条件联动编辑器)             #   弹窗/侧边面板
│                                    #   - 选择依赖字段 → 运算符 → 比较值
│                                    #   - 支持 AND/OR 嵌套组合
│                                    #   - 实时预览联动效果
│
├── /designer/drafts                # 草稿模板
│   │                                #   - 未发布的模板列表
│   │                                #   - 点击继续编辑 → 进入设计器
```

## 4. 表单填写区域 `/filler`

> 设备：PC (≥768px) + Mobile (≥375px)
> 能力：浏览表单、填写提交、管理草稿、追踪审批

```
/filler
│
├── /filler/forms                   # 可用表单 — 表单列表页
│   │                                #   - 卡片/列表布局
│   │                                #   - 按分类筛选
│   │                                #   - 关键词搜索
│   │                                #   - 空状态："还没有可用的表单"
│   │
│   └── /filler/forms/:formId       # 表单填写页 ⭐
│       │                            #   - FormEngine 渲染表单
│       │                            #   - 章节描述引导
│       │                            #   - 必填标记（红色星号）
│       │                            #   - 帮助文本（字段下方灰色提示）
│       │                            #   - 实时验证反馈（失焦校验）
│       │                            #   - 条件联动显示/隐藏
│       │                            #   - 进度指示（第 X 步 / 共 Y 步）
│       │                            #   - 自动保存指示器（"草稿已自动保存 X 分钟前"）
│       │                            #   - 操作按钮：[保存草稿] [提交申请]
│       │                            #   - 移动端：单列布局 + 底部固定操作栏
│       │
│       ├── /filler/forms/:formId/track  # 提交追踪视图
│       │                            #   - 表单内容（只读）
│       │                            #   - 审批链时间线：
│       │                            #     ● 节点1 直属上级 — 已通过 — 意见
│       │                            #     ● 节点2 IT负责人 — 审批中（高亮）
│       │                            #     ○ 节点3 财务审批 — 未开始
│       │                            #   - 撤回按钮（审批人未处理时显示）
│       │
│       └── /filler/forms/:formId/edit   # 退回修改后重新编辑
│                                    #   - 保留已填内容
│                                    #   - 标注退回原因
│
├── /filler/drafts                  # 我的草稿
│   │                                #   - 草稿列表（按最后保存时间排序）
│   │                                #   - 移动端：左滑显示删除按钮
│   │                                #   - 点击 → 恢复填写（带横幅提示）
│   │                                #   - 空状态："没有待完成的表单"
│   │
├── /filler/submissions             # 我的提交
│   │                                #   - 已提交表单列表
│   │                                #   - 每项状态标签：审批中 / 已通过 / 已拒绝 / 退回修改
│   │                                #   - 空状态："你还没有提交过表单"
│   │
│   └── /filler/submissions/:id     #   提交详情
│       │                            #   - 表单内容（只读）
│       │                            #   - 审批链状态 + 意见
│       │                            #   - 审批中 → "撤回"
│       │                            #   - 退回修改 → "重新编辑"
│       │
│       └── /filler/submissions/:id/resubmit  # 重新提交
│
└── /filler/notifications           # 通知中心（跳转公共页）
```

## 5. 审批区域 `/approver`

> 设备：移动端优先 + PC
> 核心体验：30 秒内完成审批决策

```
/approver
│
├── /approver/pending               # 待审批 — 任务列表 ⭐
│   │                                #   - 每项摘要：表单名、提交人、关键字段值、已等待时间
│   │                                #   - 空状态："没有待审批的事项 🎉"
│   │
│   └── /approver/pending/:taskId   # 审批详情页（移动端优先）⭐
│       │                            #   移动端布局：
│       │                            #   ┌──────────────────────┐
│       │                            #   │ ← 待审批              │
│       │                            #   │                      │
│       │                            #   │ 📋 摘要卡片           │
│       │                            #   │ 表单名 · 提交人 · 时间 │
│       │                            #   │ 关键字段1 · 字段2     │
│       │                            #   │ [查看完整表单 ▼]      │
│       │                            #   │                      │
│       │                            #   │ 审批意见（选填/必填）  │
│       │                            #   │ [                ]   │
│       │                            #   │                      │
│       │                            #   │ [✓ 同意] [✗ 拒绝]    │
│       │                            #   │ [↩ 退回] [🔄 转交]    │
│       │                            #   └──────────────────────┘
│       │                            #
│       │                            #   操作行为：
│       │                            #   - 同意：意见选填 → 无二次确认 → 流转
│       │                            #   - 拒绝：意见必填 → 二次确认弹窗 → 终止流程
│       │                            #   - 退回：意见必填 → 二次确认 → 退回提交人
│       │                            #   - 转交：选择转交人 → 填写原因 → 任务转移
│       │
│       └── (展开完整表单)            #   - 只读表单内容
│                                    #   - 审批链时间线可视化
│
├── /approver/history               # 已审批
│   │                                #   - 审批历史列表
│   │                                #   - 按时间排序
│   │
│   └── /approver/history/:taskId   #   历史审批详情
│                                    #   - 完整表单 + 审批链（只读）
│
└── /approver/notifications         # 通知中心
```

## 8. 横切关注点

### 8.1 通知事件驱动跳转

以下通知事件触发时，点击通知直接跳转到目标页面：

| 事件 | 通知对象 | 跳转目标 |
|------|---------|---------|
| 新审批请求 | 审批人 | `/approver/pending/:taskId` |
| 审批通过 | 提交人 | `/filler/submissions/:id` |
| 审批拒绝 | 提交人 | `/filler/submissions/:id` |
| 退回修改 | 提交人 | `/filler/forms/:formId/edit` |
| 审批转交 | 被转交人 | `/approver/pending/:taskId` |
| 提交被撤回 | 审批人 | 待审批列表（该项已消失） |
| 审批全部完成 | 提交人 | `/filler/submissions/:id` |

### 8.2 关键设计约束

| 约束 | 说明 |
|------|------|
| 导航深度 ≤ 2 层 | 最深路径如 `/designer/edit/:id` → 子面板为页面内切换，非独立路由 |
| 签出/签入状态 | 设计器编辑页自动签出，关闭/导航离开时提示签入 |
| 环境隔离 | 设计者仅在 UAT 操作；运维在 PROD 导入；填写者/审批人跨环境 |
| 移动端审批 | 摘要优先 → 折叠完整表单 → 一键操作 |
